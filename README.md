# 播客

把卡片、文章和项目文档改写成一期多人对话播客，在播客库里收听、管理，随时跳回原文。

## 能做什么

- **一键生成**：在卡片、文章或项目文档的「⋯」菜单里选「生成播客」，选好形式（双人对谈、圆桌讨论、单人讲述）、说话人的音色和时长就开始。名字由 AI 起。
- **后台生成**：生成在后台进行，进度显示在原文正文上方和侧边栏的「播客」上，切到别的页面不会中断，完成后会通知你。
- **先审稿再合成**：勾选「脚本写好后先给我看一遍」，可以先改脚本、换说话人，确认后再合成语音。
- **播客库**：侧边栏「播客」列出所有播客，每期都标着原文，点一下就能跳回去；点封面直接播放，底部的播放条在库里翻看时也不停。
- **跟读与改句**：单期详情里脚本随播放高亮，可以从任意一句开始播，或改一句只重新合成这一句。
- **原文里收听**：生成好的播客显示在原文正文上方，打开原文就能听。

## 开始使用

1. 在「设置 › 语音」里配好语音服务（需要先安装语音插件，如 MiniMax 语音）。
2. 在插件详情页的「AI 配置」里给「播客脚本」选一个模型并开启。
3. 打开任意卡片、文章或项目文档，点「⋯ › 生成播客」。

## 常见问题

**想用自己的声音？** 在「设置 › 语音」里克隆音色，之后在选择音色时会出现在「我的音色」里。

**原文删了，播客还在吗？** 在，照常可以听，原文会显示为已删除。

**播客会同步吗？** 会。播客和脚本存在笔记库里随库同步，音频文件按你的资源存储设置保存。

**删错了怎么办？** 删除后 7 天内可在插件详情页的「最近删除」里恢复。

# 播客

把卡片、文章和專案文件改寫成一期多人對話播客，在播客庫裡收聽、管理，隨時跳回原文。

## 能做什麼

- **一鍵生成**：在卡片、文章或專案文件的「⋯」選單裡選「生成播客」，選好形式（雙人對談、圓桌討論、單人講述）、說話人的音色和時長就開始。名稱由 AI 取。
- **從 Notebook 生成**：在 Notebook 的「生成」選單裡選「播客」，勾選要用的資料，AI 會先查閱資料再寫腳本；生成的播客放在 Notebook 的產物裡。
- **背景生成**：生成進度顯示在原文和播客庫裡，切換頁面不會中斷。目前頁面已顯示這期任務時，狀態會原地更新。離開後，點通知裡的「去審稿」可直達這期的腳本，點「開啟播客」可檢視生成好的音訊。
- **先審稿再合成**：勾選「腳本寫好後先給我看一遍」，可以先改腳本、換說話人，確認後再合成語音。
- **播客庫**：側邊欄「播客」列出所有播客，每期都標著原文，點一下就能跳回去；點封面直接播放，底部的播放列在庫裡翻看時也不停。
- **跟讀與改句**：單期詳情裡腳本隨播放高亮，可以從任意一句開始播，或改一句只重新合成這一句。
- **原文裡收聽**：生成好的播客顯示在原文正文上方，開啟原文就能聽。

## 開始使用

1. 在「設定 › AI 服務 › 語音」裡配好語音服務（需要先安裝語音外掛，如 MiniMax 語音）。
2. 在外掛詳情頁的「AI 配置」裡給「播客腳本」選一個模型並開啟（從 Notebook 生成時用 Notebook 的模型，不需要這一步）。
3. 開啟任意卡片、文章或專案文件，點「⋯ › 生成播客」。

## 常見問題

**想用自己的聲音？** 在「設定 › AI 服務 › 語音」裡複製音色，之後在選擇音色時會出現在「我的音色」裡。

**原文刪了，播客還在嗎？** 在，照常可以聽，原文會顯示為已刪除。

**播客會同步嗎？** 會。播客和腳本存在資料庫裡，隨資料庫同步，音訊檔案按你的資源儲存設定保存。

**刪錯了怎麼辦？** 刪除後 7 天內可在外掛詳情頁的「最近刪除」裡還原。
